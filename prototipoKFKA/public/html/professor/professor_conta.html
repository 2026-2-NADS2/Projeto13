Privacidade e uso dos dados dos alunos

Você tem acesso a dados de crianças, que a Lei Geral de Proteção de Dados (Lei nº 13.709/2018) protege de forma especial. Ao usar a KFKA:

  • Acesso restrito: você vê apenas os alunos das turmas vinculadas a você.
  • Finalidade: use os dados somente para o acompanhamento escolar; não os copie para planilhas, aplicativos de mensagem ou outros sistemas.
  • Registro mínimo: nos acompanhamentos, descreva o desenvolvimento escolar e evite informações pessoais, familiares ou de saúde que não sejam necessárias.
  • Rastreabilidade: os registros e as alterações ficam gravados no histórico do sistema, com autor e data.
  • Sessão: em computadores compartilhados, use sempre o botão "Sair" ao terminar.
