## Passo a passo para baixar o jogo

1. Abra o link do repositório e entre na pasta **Jogo**.
2. Clique no arquivo **Space Invaders Lateral.zip**.
3. Na página do arquivo, clique em **Download raw file** (ícone de seta para baixo, no canto direito da barra acima do arquivo). O arquivo vai para a pasta Downloads.
4. Extraia o zip: botão direito → **Extrair tudo** (Windows) ou dois cliques (Mac). Abrir o `index.html` de dentro do zip não funciona.
5. Abra a pasta extraída `space-invaders-lateral`. Ela contém o `index.html`, o `style.css` e a pasta `js`. Não separe esses três.
6. Dê dois cliques em **`index.html`**. O jogo abre no navegador. Clique em **Iniciar jogo** ou aperte **Enter**.

> O zip também traz as pastas `antes`, `prints` e `prints_novos`, usadas na documentação. Elas não são necessárias para jogar.

### Alternativa: baixar o repositório inteiro

Na página inicial do repositório, clique no botão verde **Code** → **Download ZIP**. Extraia e entre em `POO N1/Jogo` para pegar o zip do jogo. Esse download traz também as versões antigas e os relatórios, então é bem maior.

## Controles

| Tecla | Ação |
|---|---|
| Setas ou **W A S D** | Mover a nave nos 4 sentidos |
| **Espaço** | Atirar |
| **P** ou **Esc** | Pausar e continuar |
| **M** | Liga/desliga o som |
| **N** | Liga/desliga a música |
| **F** | Tela cheia |
| **Enter** | Iniciar ou jogar novamente |

## Se o jogo não abrir

| Problema | O que fazer |
|---|---|
| Tela em branco | Confira se a pasta `js` está ao lado do `index.html` e se o zip foi extraído de verdade. |
| Sem som | O navegador só libera o áudio depois de um clique ou tecla. Clique no jogo, aperte Enter e use **M** (som) e **N** (música). Se o botão mostrar "Som bloqueado", clique nele. |
| Jogo cortado na tela | Aperte **F** para tela cheia ou use o zoom do navegador (Ctrl e -). |
| Outra opção | No VS Code, abra a pasta, clique com o botão direito em `index.html` e escolha **Open with Live Server**. |

## Requisitos

Qualquer computador com Chrome, Edge ou Firefox atualizado. Não precisa instalar nada nem ter internet para jogar depois de baixado.
